# prompt_version: 1
# name: feet_analysis_user
这是一张人物脚部区域的裁剪图，尽量保留了脚踝和小腿上下文。请分别分析左右脚的普通袜子、鞋子和赤脚状态，并返回 json。

要求：
- left_foot/right_foot 键表示画面观察位置；每个结果必须用 person_side 表示人物自身左右（left、right、unknown）。
- side_basis 只能使用 person_own、image_side、unknown；side_confidence 使用 high、medium、low。
- 无法根据人物朝向和姿态确定人物自身左右时，person_side 使用 unknown，side_basis 使用 unknown，side_confidence 使用 low，不要猜测。
- 镜面自拍、侧面、交叉腿或裁剪缺少人物上下文时，应优先返回 unknown。
- 普通袜子类型只能使用 no_show、ankle、crew、knee_high、thigh_high、other、unknown。
- 鞋子类型只能使用 sneakers、heels、flats、loafers、boots、sandals、slippers、other、unknown。
- 普通袜子和鞋子必须分别输出；可以同时存在。
- 丝袜不属于本区域输出的独立物品；如果看到丝袜覆盖，可以记录在 evidence 中，但不要把它合并到普通袜子或鞋子。
- 只有脚部皮肤直接裸露，且没有被袜子、丝袜或鞋子覆盖时，才能判断为 barefoot。
- 脚部完全不可见时使用 not_visible，不能使用 not_barefoot。
- 一只脚穿鞋、另一只脚不穿时，必须分别记录左右脚。
- bbox 使用相对裁剪图的归一化坐标；没有把握返回 null。
- 只输出 json。
